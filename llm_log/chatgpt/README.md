# ChatGPT conversations

ChatGPT web chats are stored on OpenAI's servers, not on this machine, so they
could not be exported automatically. Put them here before submission.

## How to export

Either option works; the first keeps everything.

1. **Full export.** In ChatGPT: *Settings → Data controls → Export data*. Open
   the e-mailed zip, keep only the conversations about this project from
   `conversations.json` (or the matching pages of `chat.html`), and save them
   here as `chatgpt_<topic>.json` / `.html`.
2. **Per chat.** Open each chat, select all, copy, and paste it into a Markdown
   file here, e.g. `chatgpt_01_cluster_setup.md`. Keep every prompt and every
   reply, unedited.
